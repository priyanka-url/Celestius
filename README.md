# ✦ Celestius — A Universe of Possibilities

**Celestius** is a galaxy-inspired interactive website built with HTML, CSS, and JavaScript. It combines a celestial visual theme, immersive animations, and an interactive interface to create a unique web experience.

🌌 **Live Website:** [View Celestius](https://priyanka-url.github.io/Celestius/)

---

## ✨ Features

- **Cinematic Introduction** — A space-inspired opening screen with glowing visual effects and an interactive entry point.
- **Galaxy-Themed Design** — A dark cosmic atmosphere featuring stars, nebula-inspired visuals, and a Milky Way background.
- **Interactive Navigation** — Navigate between the Home, Events, and Connect sections.
- **Event Cards** — Explore event information through an interactive card-based layout.
- **Event Details** — View additional information about individual events.
- **Registration Interface** — A demo registration form for an interactive user experience.
- **Animated Visual Effects** — Glowing elements, transitions, and celestial-inspired styling.
- **Background Music** — Includes a music track to complement the experience.
- **Responsive Styling** — CSS-based layouts designed to provide a visually engaging experience across different screen sizes.

## 🚀 Getting Started

### Prerequisites

You need a modern web browser and a text editor to view or modify the project.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/priyanka-url/Celestius.git
   ```

2. Open the project folder:

   ```bash
   cd Celestius
   ```

3. Open `index.html` in your web browser.

For the best experience, keep all project assets in the same folder as the HTML file unless their paths in the code specify otherwise.

## 🌐 Deployment

Celestius is hosted using **GitHub Pages**.

To deploy your own version:

1. Upload the project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Navigate to **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and the `/(root)` folder.
6. Save the settings and wait for deployment to complete.
